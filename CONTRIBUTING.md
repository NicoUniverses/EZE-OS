# Contributing to EZE OS

Thank you for helping. EZE OS is maintained by EZE Capital (Switzerland) and licensed GPL-2.0-only.

1. Fork, create a branch, open a pull request against `main`.
2. Every new gate rule, decomposition or device must come with a test that checks the exact unitary
   or the exact output distribution.
3. Keep the core dependency-free. Vendor SDKs are imported lazily inside their backend.
4. Device data must cite a public source URL. Do not add unverified prices or specifications.
5. Never commit credentials, API keys or tokens.

By contributing you agree that your contribution is licensed under GPL-2.0-only.
